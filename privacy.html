Privacy policy

Last updated: 11 September 2026

Youtube Playlist Generator is a personal tool used only by its owner.

What it accesses

With the owner's permission (Google OAuth, YouTube scope), it reads public channel and video information and creates or updates playlists in the owner's own YouTube account.

What it stores

OAuth tokens are stored only on the owner's own computer (macOS Keychain). No Google user data is sent to, stored on, or shared with any third-party server, and none is sold or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
